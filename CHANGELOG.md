# Changelog

## v1.0.0

First stable release.

- Full and Lite ESPHome packages for Easun SMS hybrid inverters
- Modbus telemetry, configuration controls, alarms and fault decoding
- Home Assistant entities for PV, battery, grid, load, inverter and temperatures
- Validated support for the Easun SMS-6.2KP-W; SMS-6.5KP-W-E remains under validation
- Improved diagnostic state decoding, including PV tracking and charging status

## v0.1.0

Initial project structure

- Repository created
- Documentation started
- Official Modbus documentation added
- ESPHome integration started
